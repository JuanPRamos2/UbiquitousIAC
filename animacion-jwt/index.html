Reflexión

El JSON Web Token es importante porque permite autenticar y autorizar peticiones sin guardar sesión en el servidor: el cliente presenta un token firmado (cabecera, payload y firma) y cada servicio puede comprobar su integridad con la clave secreta, de forma stateless. Esa propiedad hace escalable la integración entre aplicaciones y microservicios, siempre que el token expire, no lleve datos sensibles y la firma se valide en cada acceso.
