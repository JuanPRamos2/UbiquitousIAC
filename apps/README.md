# apps/

Aplicaciones del monorepo:

- `web-monolito/` — librería Node en el puerto 3000
- `services/login/` — autenticación Flask en el puerto 5000 (XML/JSON + Swagger)
- `Electron_app/` — escritorio Electron: XML `/books` + portadas
- `Python_app/` — escritorio Python Tk: login, perfil, catálogo, CRUD y estado de los servicios
- `desktop-classifier/` — cliente Java SOAP
