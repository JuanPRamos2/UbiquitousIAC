# web-monolito

Librería Node.js (Express + EJS + PostgreSQL) en **http://127.0.0.1:3000/library**.

Desde la raíz del repo:

```bash
./run-library.sh
```

O:

```bash
cd apps/web-monolito
cp .env.example .env
npm install
npm run setup
npm start
```

Prompts: carpeta `prompts/` en la raíz de UbiquitousIAC.
