Catálogo del microservicio Flask

El mismo servicio SOAP publica /books. Sin parámetro responde XML. Con ?format=json responde JSON.

Arranque

cd UbiquitousIAC
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export FLASK_APP=app.py
flask run --host=0.0.0.0 --port=5001

Abrir JSON Abrir XML Probar SOAP
