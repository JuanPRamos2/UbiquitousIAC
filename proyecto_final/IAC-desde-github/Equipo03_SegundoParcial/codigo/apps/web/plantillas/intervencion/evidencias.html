Cada archivo se guarda bajo el SHA-256 de su contenido, no bajo el nombre que manda el navegador. Por qué no se pueden modificar

Una corrección se carga como archivo nuevo, con su propia fecha; el anterior se conserva. Es la misma regla que documents-service aplica a las evidencias de consentimiento y por el mismo motivo: una evidencia que se puede editar después no sirve como evidencia. Al descargar, el sistema recalcula el SHA-256 del archivo y lo compara con el registrado; si no coinciden, no lo entrega y lo deja anotado en la bitácora.
