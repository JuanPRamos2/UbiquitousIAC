Abrir la plataforma

En ubiquitous Apache no corre Node. El login contra /api falla si no hay Docker. En esa copia ahora puedes entrar con demo123 para recorrer menús; las encuestas reales siguen necesitando Compose en local.

Entrar a Nexum Prototipo Wireframes

En el servidor de evidencias no corre Node. Para usar cuentas demo, levanta Compose en tu máquina y abre http://127.0.0.1:3000.

Arquitectura

Un solo proceso Node/Express. Tres almacenes, sin JOIN entre Mongo y Postgres. El único puente identidad ↔ operativa es consentimiento.seudonimo.

PostgreSQL Cuentas, catálogos, consentimiento, umbral k.
MongoDB Encuestas seudonimizadas y bitácora.
Redis Sesión JWT, caché de agregados, candados, intentos de login.
Express API /api y archivos de web/.

Detalle: docs/arquitectura.md.
