Tarea 4: interoperabilidad

Juan Pablo Ramos Salazar · 610248

Objetivo

Demostrar que el WSDL permite que un cliente en otro lenguaje consuma el mismo servicio sin conocer su implementación interna.

Herramienta y lenguaje

zeep en Python. Lee el WSDL y construye las llamadas. No arma el Envelope a mano. El módulo, en cambio, sí construye XML nodo a nodo. Esa diferencia es la evidencia de interoperabilidad.

Proceso de generación del cliente

cd ejercicio03/clients/zeep
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python cliente_zeep.py --wsdl http://localhost:5000/soap?wsdl --operacion pendientes
python cliente_zeep.py --wsdl http://localhost:5000/soap?wsdl --operacion registrar --concept-id 101 --isbn 9780132350884 --modelo IaaS

Código relevante

client = Client(wsdl)
result = client.service.ObtenerConceptosPendientes(
    correo="juan.pablo@udem.edu",
    tipoCliente="zeep-python",
)
client.service.RegistrarClasificacion(
    nombre="Juan Pablo",
    apellidos="Ramos Salazar",
    correo="juan.pablo@udem.edu",
    conceptId=101,
    isbn="9780132350884",
    modelo="IaaS",
    tipoCliente="zeep-python",
)
